# Engine 杀毒引擎

基于 Win32 API 开发的轻量级杀毒软件，提供文件扫描与威胁检测功能。

## 功能

- **快速扫描** — 对系统关键目录进行快速检测，秒级完成扫描
- **自定义扫描** — 用户自行指定扫描范围，支持单文件或任意目录

## 环境要求

- Windows 10 / 11
- Visual Studio 2022
- 平台工具集：v143，目标平台：x64

## 构建

用 Visual Studio 打开 `WindowsProject1/WindowsProject1.slnx`，选择配置（Debug / Release），按 `Ctrl+Shift+B` 编译即可。
